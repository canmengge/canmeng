## 一、这是什么项目

| 项 | 内容 |
| --- | --- |
| 技术栈 | Go（wails3 内核 + 服务层）+ Vue3 / TypeScript（前端） |
| 当前版本 | **4.3**（正式版已上线，2026-09-28） |
| 线上站点 | `https://www.mengfly.fun/pvf/` |
| 清单地址 | `https://www.mengfly.fun/pvf/updates/windows/amd64/stable.json` |
| 开发模式 | 日常走 **HMR 热更新**（改前端不构建、不打包，秒级生效）；只有改 Go 才重新构建 |

## 四、日常流程（与搬迁前一致）

| 场景 | 操作 |
| --- | --- |
| 改前端 UI（日常主通道） | 双击 `04-运行环境\HMR 热更新\启动HMR热更新.cmd` → 改 `.vue` / `.ts` 保存 → 界面约 1 秒生效 |

| 保存进度 | 对 AI 说 **`保存进度`** → 更新 `03-工作对接快照.md` 三处 + 一次 git 提交 |
| 开启新对话 | 对 AI 说 **`读规则`** → AI 读 `01-项目开发规则.md` §0 + `03-工作对接快照.md` + `源码落点速查.md` 第五节踩坑表 |

## 五、硬性注意事项

1. **`01-源码` 是唯一真源**：编辑器的代码改动一律落在这里，改完让 AI 提交一次 git。
2. **大文件不进 git**：exe / `.pvf` / npk / 交付包一律放 `04~07`（`.gitignore` 已排除）。
3. **`.cmd` 脚本必须 GBK(936) 编码**：cmd.exe 按系统 ANSI 读，UTF-8 会中文乱码、连中文文件名都解析失败。
4. **改 PVF 编辑器 ≠ 改游戏数据**：未经明确指令不覆盖客户端 `D:\115us\DFO_2.31.1.117\Script.pvf`。
5. 未搬迁的只读参考目录（`pvfine-main-源码-0.6`、`pvfine-main`、`_基准`、`外置知识库`）仍在 `d:\115us\PVF Ai Agent\` 或 `d:\110AI\本人备份AI不要动\` 下。
