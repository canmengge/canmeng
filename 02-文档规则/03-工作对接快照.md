    - **P4 普通文件内存与响应式瘦身** —— 现状：`tab.text` + `tab.original` 持两份；`CodeEditor` 的 `watch(props.doc)` 每次切档都 `doc.toString()`（O(文档)）；`refreshAfterArchiveChange` 对所有 tab 重拉｜方向：原文 hash 判脏 / `lastEmitted` 短路 / 跳过 largeFile tab｜预期：切档更顺、内存少一份文本。
    - **P5 大文件行偏移开销（本轮引入，诚实列出）** —— 现状：`GetFileLines / SetFileLines` 每次都全扫文本算行偏移（≈20 ms/次，滚动跨段时触发）｜方向：每文件一份"行偏移表 + 版本号"，写回后失效重算｜预期：定位降到 O(1)。
    - **P6 全量体检清单（同一课推广）** —— 挨个检查"整个数据集塞进 DOM / 内存"的地方：搜索视窗结果、字符串表预览、批处理 diff、AI 上下文、书签 / 文件集加载。
    - **P7 保存 PVF** —— 现状：**11.4 秒**（整包原子写 543 MB）｜方向：**补进度 + 可取消**（红线：长任务必须可取消）｜**用户点名的下一步（他说的"P0-7"就是这一项）**。
