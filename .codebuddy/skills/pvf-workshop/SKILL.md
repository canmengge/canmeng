## 三、常用操作 → 用哪个脚本

所有脚本在 `scripts/` 下，**PowerShell 直接跑**（本机 `python` 不可用，脚本一律用 PowerShell）。

| 要做的事 | 命令 |
| --- | --- |
| 构建开发版 exe + 核验 + 打印该告知用户的原话 | `scripts/build-dev.ps1` |
| 核验正式版 exe（PE 头 / 图标 / 版本 / 内嵌字面量 / 哈希） | `scripts/verify-exe.ps1 -Exe "<exe路径>" -Literals "4.6.0","取消封包"` |
| PVF 内容分析（列文件 / 统计扩展名 / 读单文件 / 搜索 / 按清单提取） | `scripts/pvf.ps1 -Action <动作> [...]` |

> `pvf.ps1` 每次都要重新打开 544 MB 的归档（约 10 秒），**一次调用只做一个动作**；需要多次分析时先把路径清单导出成文件复用。

### ⚠️ 脚本编码（改写脚本前必读）

本技能三个 `.ps1` 一律存为 **UTF-8 with BOM**（原因与自查见踩坑 **#26**；与"`.cmd` 要 GBK"**正好相反**）。

改写脚本后用下面这句补回 BOM：

```powershell
$p = "<脚本路径>"
$t = [System.IO.File]::ReadAllText($p, [System.Text.UTF8Encoding]::new($false))
[System.IO.File]::WriteAllText($p, $t, [System.Text.UTF8Encoding]::new($true))
```

自查：`[System.Management.Automation.Language.Parser]::ParseFile($p, [ref]$null, [ref]$errs)`，`$errs.Count` 必须为 0。

   ```powershell
   scripts/check-frontend-live.ps1 -File "src/components/FormView.vue" -Marker "<本轮标记串>"
   ```

   直接问 dev server 要刚改的文件，看响应里有没有本轮标记串：**exit 0 = 用户可以测；exit 1 = dev server 在吐旧代码，禁止说"能测了"**，先让用户重跑 HMR 脚本重启 dev server 再查。
