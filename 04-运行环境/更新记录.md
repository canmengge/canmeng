# PVF工坊 更新记录

> 写给使用本工具的朋友：下面按"对您有什么用"来讲，尽量不说技术黑话。所有版本按时间顺序排列，方便您对照。

## 一、最初版本（原版编辑器）

这是本工具的起点——一个能打开、浏览、修改 DNF（地下城与勇士）PVF 归档的编辑器。当时能做的事：

- 打开 PVF 归档，浏览里面的文件目录。
- 点开单个文件查看、修改内容。
- 按名称做基础搜索。

打开一个 500 多 MB、430 多万个文件的大归档大约要 12~14 秒。这个速度后来成了后面所有版本的"及格线"。

## 二、1.0 版 · 第一次大改（2026-09-24）

在原版基础上，加了一批"更懂 PVF、改起来更顺手、更安全"的能力：

- **智能字段提示**：字段说明库从原版的 37 个扩充到 5,651 个，编辑时把鼠标放上去、或输入补全，就能看到这个字段的含义、单位和取值范围。
- **对象视图**：输入一个对象（装备、道具等）的 ID，把横跨 4~6 个文件的相关内容（脚本、显示文本、登记表、索引、引用方）聚合到一个面板里，不用再一个个文件翻。
- **字符串表安全写保护**：误改会导致整片界面乱码的"禁动表"会被当场拦下，并给出正确改法；确实要改时，用「改写到安全表」一键完成。这个保护默认关闭，可在「设置」里打开。
- **预览更准确**：预览图下方的「介绍 / 详细介绍」不再显示 `<3::...>` 这类看不懂的符号。
- **打开大归档提速**：修好了"打开 500 多 MB 归档要等近 3 分钟"的问题，回到约 11 秒。

> 小插曲：1.0 因为加了大量字段提示，一度让打开速度从 12 秒退步到近 3 分钟；随后已单独修复（就是上面最后一条"提速"）。

## 三、2.0 版 · 整合提速（2026-09-24）

把 1.0 的全部功能，重新建立在原版的性能骨架上，做到"**功能一样全，速度回到原版水平**"：

- 打开大归档约 11~14 秒，与原版持平，不再有 1.0 那种"看起来像卡死"的等待。
- 1.0 的全部能力都完整保留。

这个版本是首个面向使用者的完整交付（当时名叫「PVF 编辑器 2.0」）。

## 四、2.1 ~ 2.10 · 界面与搜索打磨（2026-09-24）

这一批主要让日常用起来更顺手：

- **搜索结果双击定位**：高级搜索的结果，双击就能打开文件并滚动到命中处，整行高亮。
- **命令面板**：按 `Ctrl+P` 或 `Ctrl+K`，输入文件名或 ID 秒开；也能执行命令。
- **常用快捷键**：`Ctrl+Shift+F` 高级搜索、`Ctrl+B` 侧栏、`Ctrl+O` 打开归档。
- **打开更快**：搜索索引改成"用到才建、空闲自动补"，打开归档不再被它拖慢。
- **归档体检**：右侧盾牌面板，可查看文件数、目录数、扩展名分布、字符串表指纹等信息。
- **批量替换预览增强**：改之前先看清楚会改到哪些文件，可逐个打开确认。
- **文件树更清爽**：行距贴紧、显示中文名标签、目录带注释，深层目录不会再缩到右边溢出。
- **状态栏显示版本号**：右下角能直接看到"版本号2.N"。

## 五、2.11 ~ 2.14 · 界面布局与搜索视窗（2026-09-24 ~ 25）

- **分屏合并成一个下拉**：左右分屏、上下分屏统一成一个下拉，放到工具条最右侧。
- **文件信息标签单独一行**：物品 ID、中文名、路径三个标签点一下即可复制。
- **新增「搜索视窗」**：右侧集中查看面板，文件树里点右键「添加到搜索视窗」即可加入。
- **搜索视窗显示对齐左侧**：里面的文件夹和左侧文件树一样带注释，文件后面只显示中文名，不再冒出一串编号。
- **预览「介绍 / 详细介绍」解析**：与名称一致，正确显示中文。

## 六、2026-09-25（本次更新 · 2.15 ~ 2.19）

### 启动不再弹黑窗口

以前每次打开，旁边都会跟着弹出一个黑底白字的日志窗口，很碍事。

现在这个黑窗口**彻底去掉了**。日志照常记录，只是安静地写到工具目录下的 `pvfine-main` 文件夹里，界面右下角也能随时查看，您不用管它。

### 大文件也能打开了

以前超过 8 MB 的文件，点开只会看到一行"文件过大"的提示，想看内容看不了。

现在：

- 可以到「设置 → 代码编辑器 → 文本编辑上限」，把上限调高（8 / 16 / 32 / 64 MB，或不限）。
- 特别大的文件打开前会先问您一声，确认后再开。
- 打开后先以**只读**方式显示（同时自动关掉折行和空白标记，避免卡顿），想改再点顶部的「允许编辑」。

### 工具栏新增「对象视图」入口

原来对象视图只能从右侧栏点出来，现在顶部工具栏直接有「对象视图」按钮，点一下就在右侧打开。

### 默认打开「对象视图」

打开工具后，右侧栏直接停在「对象视图」，不用再手动切过去。

### 缺少 sk.dat 时的友好提醒

打开归档时，如果旁边缺少配套的 `sk.dat` 文件，会弹出醒目的提醒（可以点击关闭），告诉您该去确认这个文件。

### 正式更名

正式更名为「PVF工坊 · 基于 pvfine 修改 · By 残梦断忆」。

### 内置 AI 助手（2.19 · 默认关闭，需自行配置模型）

工具里新增了一个「AI 助手」面板，可以像聊天一样用大白话：

- **问知识**：比如"装备的 `[name]` 字段是什么意思""这个表号对应哪个文件"，AI 会基于工具内置的注释数据回答。
- **查文件**：让 AI 帮你搜文件、读文件内容、看某个对象的全貌。
- **要改东西先过保护**：默认开启「AI 写保护」，AI 只能看不能改；确需让 AI 动手时，在面板把开关关掉即可（修改仍受字符串表保护与保存前备份约束）。

怎么开启：

1. 打开「设置 → AI 助手」，打开「启用 AI 助手」。
2. 选一个模型服务商（DeepSeek / 通义千问 / Kimi / Ollama / 自定义），地址和默认模型会自动带出，可再手改。
3. 填入你的 API Key（本地 Ollama 可留空），点「测试连接」确认可用。
4. 回到右侧栏「AI 助手」面板开始提问。

> [!TIP]
> **[提示]** 地址、模型、Key 填完后，点「**保存 AI 配置**」按钮提交（在输入框里按回车、或点击其它位置也会自动保存）；填完记得点「测试连接」确认可用。

说明：**工具本身不内置任何模型、也不替你付费**——用哪家的模型、花多少，由你自己决定；Key 只保存在你电脑的设置文件里。

### 更新方式说明

本版本不连接任何在线更新频道；需要新版本请联系作者获取。

## 七、2026-09-25（本次更新 · 2.21 ~ 2.22）

### 一、高级搜索大提速（本次重点）

这次把高级搜索整个重做了一遍，比之前**快很多、也更跟手**：

- **字符串搜索更快**：以前每搜一次都要把整张字符串表从头扫一遍、还要做大小写转换；现在改成「先建好索引、直接查」，大归档下也明显更快。
- **翻页几乎秒开**：搜索结果加了缓存，第二页、第三页不用重新算，直接翻，不再一页一页等。
- **改完文件立即生效**：以前改一个文件，整个搜索索引全部作废、下次搜索要重建；现在只更新改动的那一个文件，改完立刻能搜到最新内容。
- **首次搜索不再卡界面**：首次搜索改为**后台**建索引，界面不会「假死」；建索引期间右下角会显示进度。
- **二次打开同一个归档几乎立刻可用**：索引会存到本地缓存，第二次打开直接读缓存，不用重建。
- **二进制搜索同样提速**：二进制（原始字节）搜索也加了缓存，重复搜同一个内容更快。
- **一次拉取更多结果**：导出/一次性加载结果时每页取的条数提高，减少来回等待。

### 二、修复导入字符串表报错

以前用「导入文件」导入 `.str` 字符串表，会弹出「文本文件 … 不是有效的 UTF-8」并失败。

**原因**：这类字符串表在 PVF 里实际是 **UTF-16 编码**，而工具之前只认 UTF-8，属于工具自身的判断缺陷。

**现在**：导入时**自动识别编码**——UTF-8、UTF-16（带 BOM / 不带 BOM）都能正确识别并导入，字符串表可以正常导入了。

### 三、彻底关闭自动更新

- 设置界面不再显示「检查版本更新」这一项。
- 程序不会在后台联网检查更新，也不会自动下载安装。
- 需要新版本请联系作者获取。

### 四、AI 助手新增「删除密钥」

「设置 → AI 助手」的 API Key 输入框旁新增**「删除密钥」按钮**：点一下（二次确认后）即可把保存在本机的 API Key 清除，避免私人密钥遗留在电脑里。

### 五、工程与交付约定（内部说明，可不看）

- 台账（本文件、使用说明）改为**按需编写**：只在明确要求时更新，日常开发不再逐次写记录，以质量与效率优先。
- 测试包统一命名为 `测试2.<序号>.exe` 放到根目录，方便一眼找到最新测试版。

## 八、2026-09-26（本次更新 · 2.23 ~ 2.56）

### 一、AI 助手：更聪明、更快、更直观

- **想停就停**：AI 回答时按钮会变成"停止"，点一下立即终止，不用干等。
- **边想边显示**：回答像打字一样逐字出现，AI 正在用哪个工具（搜文件、读文件…）也实时可见，不再"转圈等结果"。
- **找文件大提速**：搜索结果按相关度排序（一次就给最像的），还能限定只在某个目录里找；一次对话能用的工具步数翻倍。
- **自带资料库**：内置 2800+ 篇社区教程与字段注释（`知识库` 文件夹），问语法、字段含义、脚本写法时 AI 会先查资料再回答。
- **新手教程**：第一次用 AI 时，面板里直接给出四步配置引导；配置启用后教程自动消失。
- **修复**：回答中途"突然不说话"（以前 60 秒就被硬性掐断，现在 15 分钟）、推理型模型返回空内容等问题。

### 二、注释可以自己写了

在左侧文件树或编辑区点右键「**编辑注释**」：给任意文件/文件夹写自己的注释（比如把某个文件夹标成"我的常改商店"）。保存立即生效、重启仍在；也能一键恢复软件默认。客户的注释保存在自己电脑的配置目录里，互不影响。

### 三、高级搜索整个重做

- 弹窗即搜即用：结果**四列对齐**（类型 / 名称 / ID / 路径），列宽可以像表格一样**拖着竖线左右调**。
- 点一下某行：固定高亮，方便锁定目标。
- 「**打开并定位**」一个按钮搞定三件事：打开文件 + 左侧文件树展开定位 + 关闭搜索框；**双击结果**同样生效。
- 新增「**添加视图**」页签：全选或勾选搜到的文件，一键批量送进右侧搜索视窗。

### 四、搜索视窗与文件树彻底联动

- 点击搜索视窗里的文件：打开文件 + 左侧文件树展开定位到它。
- 右键菜单与文件树一致：复制路径 / ID / 名称、加入书签、加入文件集、编辑注释、AI 引入。
- 显示与文件树完全一致（ID + 中文名标签）。

### 五、导入窗口重构（支持批量与冲突处理）

- 左侧"待导入列表"：**拖拽文件/文件夹**即可加入（可一次拖多个），也有内置的本地目录选择器——**勾选一个文件夹 = 整个文件夹（含所有子内容）导入**，文件与文件夹可混合多选。
- 右侧属性面板：**从目录树选择导入位置**；**文件冲突处理四选一**（覆盖 / 重命名 / 跳过 / 终止）；可选"导入后添加到搜索视窗"。
- **导入完成后索引秒级刷新**：新导入的文件立刻有中文名、注释，马上就能被搜索，不用重启。

### 六、书签弹窗升级

- 默认尺寸改为 **368×369**。
- 头部新增：**重命名当前书签簿**（点 ✏️ 直接改）、**导入书签簿**、**导出书签簿**。

### 七、界面细节与修复

- 文件树 / 书签界面重绘：行首图标、目录名加粗、悬停与选中高亮更清晰。
- 已打开的文件右键新增「**刷新文件内容**」。
- 修复：左侧搜索后"取消搜索"会把结果弄丢（现在自动收进搜索视窗）、搜索视窗点击不定位、AI 回复中断报错、书签弹窗尺寸遗留等多项问题。
